# Hospital Appointment Booking System

## Project Description

The Hospital Appointment Booking System is a web application that facilitates the scheduling and management of patient appointments in hospitals. This system aims to enhance the patient experience by allowing easy booking, cancellation, and management of appointments while providing hospital staff with efficient tools to handle their schedules.

### Key Features

- **User Authentication**: Secure login for both patients and hospital staff.
- **Appointment Booking**: Patients can view available time slots and book appointments with doctors.
- **Appointment Management**: Hospital staff can view, accept, or cancel appointments as needed.
- **User Profiles**: Patients can manage their profiles and check their appointment.
- **Responsive Design**: Optimized for both desktop and mobile users.

### Technologies Used

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
